# ADR-0013: 분석 검증용 외부 실데이터

- 날짜: 2026-11-02
- 상태: 채택
- 관련: #29, #30, #31, AN-0001, ADR-0004

## 상황

- 다나와 데이터와 연습 쇼핑몰 목데이터만으로는 우리 분석과 알고리즘이 맞는지 스스로 증명할 수 없다. 사용자가 "다른 신뢰할만한 대량의 분량의 실데이터 검증을 병행해서 다른 분석과 비교"하자고 했고, 검증을 라벨 있는 벤치마크, 연구 결과 재현, 공식 통계 대조로 나누는 계획을 확정했다 (devlog 2026-11-01).
- 다나와 과거 최저가 그래프는 `/info/ajax/`로 불러와서 robots.txt 때문에 쓸 수 없다. 다나와는 쌓이는 만큼만 쓴다.
- 비용을 들이지 않는다 (ADR-0003). 계정 가입, 약관 동의, 로그인은 사용자가 직접 한다.

## 선택지와 확인한 것

| 후보 | 비교 대상 | 접근 | 이용 조건 | 판단 |
|---|---|---|---|---|
| TCPD | 사람이 표시한 변화점 라벨 | GitHub 공개 | 코드 MIT, 데이터는 시계열별 (일부 재배포 불가) | 쓴다 |
| TCPDBench 결과 | 같은 시계열에 돌린 알고리즘 14개 점수 | GitHub 공개 | MIT | 쓴다 |

| 참가격 Open API | 판매점별 과거 이력 | 회원가입·활용신청·키 | 출처표시(제1유형) | 쓴다. 키를 받은 뒤 |
| 통계청 소비자물가 품목 지수 | 공식 통계 | KOSIS 키 | 무료 | 쓴다. 키를 받은 뒤 |

| KAMIS 농산물 가격 | 1996년부터 일별 시장 가격 | 키 | 확인 안 함 | 보류. 위 데이터로 모자라면 다시 본다 |

데이터별 출처, 판, 규모는 `analysis/datasets.md`.

## 결정

- 변화점·급락 감지(#30)는 TCPD 라벨과 TCPDBench 점수로 검증한다. 논문과 같은 지표(F1, cover)를 쓰면 공개된 14개 알고리즘과 바로 비교된다.
- 판매점 비교·할인 판별(#31)은 참가격으로 하고 통계청 품목 지수와 대조한다. 지금 받은 파일은 한 달치(조사일 2회)라 과거 이력은 Open API로 받는다.
- Cavallo 자료는 사용자가 받아 주면 원자료가 있는지 보고 #31에 넣을지 정한다. 키·로그인이 필요한 데이터는 #37에서 받는다.
- 위 선정은 Claude가 했다. 검증을 세 층으로 하자는 큰 방향은 사용자가 정했다.

## 받는 방식

- 받은 파일은 `analysis/data/external/`에 두고 커밋하지 않는다. 데이터마다 재배포 조건이 다르고(TCPD 일부는 재배포 불가), 저장소를 공개할 때 문제가 없게 하려는 것이다. 저장소에는 목록(`analysis/datasets.md`)과 받기 스크립트(`analysis/fetch_external.py`)만 둔다.
- 저장소는 커밋을 고정해서 받는다. 공공데이터포털 파일은 판 이름과 sha256을 적는다. 같은 판으로 다시 받아 결과를 재현할 수 있게 하려는 것이다.
- 다른 저장소의 스크립트는 실행하지 않는다 (TCPD의 `build_tcpd.py` 등). 그래서 TCPD 시계열 10개는 지금 없다. 필요해지면 원 출처를 하나씩 확인하고 받는다.
- 공공데이터포털은 사이트의 다운로드 횟수 확인을 거친다. 보안문자를 요구하면 멈추고 사람이 브라우저에서 받는다.
- 참가격 Open API 결과를 쓰는 분석 노트와 화면에는 출처(한국소비자원 참가격)를 적는다.

## 감수하는 것

- 키가 필요한 데이터는 사용자가 가입과 신청을 해야 시작할 수 있다. 그동안 #31은 한 달치 파일로만 해 볼 수 있다.
- TCPD는 가격 데이터가 아니다. 경제 계열(유가, 환율, GDP 등)이 일부 있지만, 여기서 맞는 알고리즘이 다나와 가격에서도 맞는다는 보장은 없다. 그래서 #30은 TCPD 점수와 다나와 적용 결과를 같이 본다.
- 참가격은 오프라인 매장(대형마트, 슈퍼, 백화점) 중심이고 온라인 오픈마켓과 가격 움직임이 다를 수 있다.
