# 포트폴리오용 정리

분석 노트(AN-0001~0005)를 읽는 사람에 맞춰 다시 정리한 문서. 원래 분석 노트는 과정 기록이라 고치지 않고, 여기서 요약하고 링크한다.

| 문서 | 읽는 사람 | 내용 |
|---|---|---|
| [analysis-for-clients.md](analysis-for-clients.md) | 외주 의뢰인 (온라인 셀러 등) | 무엇을 확인했고 제품에 어떻게 썼나. 기술 용어를 줄였다 |
| [analysis-technical.md](analysis-technical.md) | 개발자, 채용 담당 | 방법, 공개 점수·논문 재현으로 한 검증, 틀렸던 판단, 한계 |

## 저장소 밖에서 쓸 때

- 두 문서는 각각 따로 읽어도 되게 썼다. 그림은 `docs/assets/`의 PNG를 상대 경로로 넣었으니, 옮길 때는 그림 파일도 같이 옮기거나 경로를 바꾼다.
- 분석 노트, ADR, TS로 가는 링크는 저장소 안 상대 경로다. 저장소가 비공개라면 밖에서는 링크가 열리지 않는다. 링크를 빼거나 해당 문서를 같이 공개한다.
- 다나와 수집 데이터는 공개하지 않기로 했다(README "지금 동작하는 것"). 두 문서의 그림 중 [an0001-cases.png](../assets/an0001-cases.png)는 다나와 상품 3개의 최저가 추이라, 저장소 밖에 공개할 때 넣을지는 따로 정해야 한다. 집계 숫자(시간당 변동 10.7% 등)도 다나와 데이터에서 나온 것이다.
- 숫자는 2026-11-24 기준 분석 노트의 값이다. 노트가 갱신되면 여기도 맞춘다.
