# 2026-11-05 (목)

## 한 일

- 사용자가 Healthchecks 경고 화면과 DOWN/UP 메일을 보여 줬다. 11-04 19:17, 20:17, 11-05 00:17 KST 세 번의 수집 누락 원인을 찾아 [TS-0006](../troubleshooting/0006-healthchecks-down-dns-and-missing-run.md)에 남겼다 (#51).

## 문제

- 19:17: Actions 러너에서 `prod.danawa.com` 이름 풀이 실패, 다나와 20개 모두 실패
- 20:17: cron-job.org 호출에 GitHub API가 500. GitHub 장애(11-04 09:49~11:50 UTC) 시간 안
- 00:17: cron-job.org가 호출하지 않음. 실행 기록에 항목이 없고 설정은 정상

## 판단과 근거

- cron-job.org 실행 기록은 로그인이 필요해서 사용자가 내장 브라우저에서 로그인했다. 작업 설정은 읽기만 했다.
- 매시 47분 예비 호출을 제안했다. 스케줄러 규칙상 코드 변경 없이 빠진 시만 보충하지만, Actions 사용 시간이 월 최대 744분(추정) 늘어 3,000분 한도에 가까워진다. 사용자가 "예비호출은 안해도 될 거 같아"라고 해서 두지 않았다.
- 수집기 연결 재시도는 제안하지 않았다. 이번 세 번 중 어느 것도 짧은 재시도로는 막지 못한다고 Claude가 봤다.
